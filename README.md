# Komentář k zákonu č. 471/2011 Sb., o mezinárodní pomoci při vymáhání některých finančních pohledávek

Otevřený komentář k zákonu o mezinárodní pomoci při vymáhání některých finančních pohledávek — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; organizační zabezpečení, výměna informací, doručování, vymáhání a zajištění pohledávek podle směrnice 2010/24/EU a mezinárodních smluv.

Konsolidované znění: dokument e-Sbírky `SB-2011-00471_2023-01-01`.
